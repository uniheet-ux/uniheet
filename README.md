# مكتبة الجامعة — نظام المبيعات والفواتير

برنامج Windows عربي للمبيعات والفواتير، يعمل على جهاز رئيسي وجهاز فرعي داخل الشبكة المحلية.

## التشغيل

1. ثبّت البرنامج على الجهازين من ملف `UniversityLibraryPOS-Setup.exe`.
2. في الجهاز الرئيسي اترك خيار **هذا هو الجهاز الرئيسي** مفعّلًا.
3. اعرف عنوان IP للجهاز الرئيسي، وافتح المنفذ `5088` في جدار حماية Windows.
4. في الجهاز الفرعي ألغِ خيار الجهاز الرئيسي، واكتب العنوان مثل `http://192.168.1.10:5088`.
5. استخدم رمز الاتصال نفسه في الجهازين ثم أعد تشغيل البرنامج.

قاعدة البيانات محفوظة على الجهاز الرئيسي في `C:\ProgramData\UniversityLibraryPOS\sales.db`.
